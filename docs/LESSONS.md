# Negotiation lessons (cross-run memory)

Every lesson comes from saved hosted conversations (ours and the teammate's replays), is stated as a
**general rule over public case features or what the supplier says in the current thread**, and is
enforced in code with a regression test. Lessons never name a practice supplier or use its scores,
`c_best` or replays as live inputs: hidden final suppliers are new. A lesson is kept only while new
evidence supports it; contradicting evidence is recorded, not deleted.

Status: **enforced** (in code + test), **hypothesis** (supported, not yet enforced or validated), **retired**.
